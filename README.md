# NetSage AI

Network topology diagnostics using Gemini and a standard-library Python rule checker.

## Run Locally

**Prerequisites:** Node.js and Python 3. The Node server and `checker/rule_checker.py` must be installed locally; the checker uses only the Python standard library and needs no pip packages.


1. Install Node dependencies: `npm install`
2. Copy `.env.example` to `.env` and set `GEMINI_API_KEY`.
3. Run the app: `npm run dev`
   `npm run dev`
